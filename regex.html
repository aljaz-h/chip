01Start from a preset

In Nuvio, Auto-play regex match keeps the streams whose text matches one pattern and plays the first playable one in list order. The pattern filters, it does not rank. This page builds that pattern and shows which stream Nuvio would pick.

    04Use it in Nuvio

    1. Open Nuvio Settings → Player and find Stream and Auto-Play.
    2. Set Auto Stream Selection to Auto-play regex match.
    3. Paste the pattern into the regex field. Keep a short timeout in mind: Nuvio plays the best match found when it runs out.

    Menu names can differ between versions and between the phone and TV apps. The regex setting syncs with your profile, so it applies on every device.

    05How it works, and limits

    Taken from reading the open source NuvioTV and NuvioMobile selectors. Nothing is copied from them.

    • The pattern is case-insensitive and only has to match somewhere in the text. The text is the addon name, stream name, label or title, description (with its line breaks) and any direct link, joined by spaces.
    • Nuvio also pulls words out of negative lookaheads like (?!.*\b(cam|ts)\b) and rejects streams containing them. Keep those words plain.
    • . does not cross line breaks unless the pattern starts with (?s). The builder adds it.
    • Nuvio uses Java-style regex, this page tests with JavaScript regex. They agree on everything the builder writes, but patterns you type by hand can differ. Possessive quantifiers, atomic groups and \Q…\E are flagged.
    • It matches text only. The test streams are invented, and your addon's real text decides what happens. Use Custom text to paste real stream text.
    • Which stream is first depends on your addon order and each addon's own sorting, so the order here is a guess you can rearrange.
