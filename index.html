01 Start

Pick a look, choose the badges you want, copy the JSON. Everything runs in your browser and nothing is uploaded.

Imported badges keep their own colors. Badges that are not in the file are switched off, and unknown ones are added as custom badges.

04 Export

Nuvio asks for a link to the JSON, not the JSON itself. Create import URL uploads your pack to a public paste service and gives you a link to paste into Nuvio. The pack contains only badge rules, no personal data.

Health check
    Your artwork

    Your design is drawn as one SVG per badge. Nuvio needs to download them from a public address.

    1. Unzip it into your repo's badges/ folder so the files sit at badges/custom/, then push.
    2. Leave "Hosted at" empty if this site is on the same repo. Otherwise set it to where custom/ lives.
    Get it into Nuvio
    1. Click Create import URL above and copy the link.
    2. In Nuvio open Settings → Streams → Fusion badge URLs (Android TV: Settings → Layout → Streams). Menu labels can differ between versions.
    3. Paste the link, tap Import, then select it as the active pack. Nuvio stores the rules on import, so the badges keep working if the link later expires.

    Want a link you can edit and re-import later? Put the JSON in a public GitHub Gist and use its raw link. The converter below turns a normal Gist or Pastebin link into a raw one.
