04 Export

Import URL for Nuvio
Create a token

One-time setup: create a token that only has the gist permission, then paste it here. It stays in this browser and is only sent to api.github.com. Your pack becomes a public Gist whose link never changes, so you can update the badges later and keep the same URL.

  1. Click Copy JSON & open Gist below. The pack is copied and gist.github.com opens in a new tab.
  2. Paste it into the box, name the file chip-badges.json, choose Create public gist.
  3. Paste the gist's page address here to get the link for Nuvio.

Health check
    Your artwork

    Recommended. Badger uses the same approach. Nuvio reads the images from the pack itself, so the link alone is enough. If badges come out empty in Nuvio, untick this and host the files instead.

    Or host the files yourself
    1. Unzip it into your repo's badges/ folder so the files sit at badges/custom/, then push.
    2. Leave "Hosted at" empty if this site is on the same repo. Otherwise set it to where custom/ lives.
    Get it into Nuvio
    1. Get your link with the button above and copy it.
    2. In Nuvio open Settings → Streams → Fusion badge URLs (Android TV: Settings → Layout → Streams). Menu labels can differ between versions.
    3. Paste the link, tap Import, then select it as the active pack. Nuvio stores the rules on import.

    Why Gist? It is what Nuvio badge packs are normally shared with, its link never changes when you update the pack, and its security certificate is accepted by older devices. Some free paste sites are not.

    Preview

    Nuvio rounds the corners of every badge and cuts off anything outside the curve, even sharp-cornered artwork. This switch shows the preview that way. Turn it off to see the artwork as drawn.
